# 项目边界

## 必须属于 Agent-VideoNote

- 本地视频输入
- FFmpeg / ffprobe 封装
- 主 ASR 接口
- 局部 ASR 复核接口
- 热词 / 课程上下文
- 可续跑任务状态
- 任务中间产物目录
- 画面候选提取
- 视觉清理策略接口
- 工作流阶段定义
- 最终交付结构检查
- MCP 等外部适配器

## 第一阶段明确不做

- 自动写“总结型笔记”
- 通用 LLM Provider 管理
- OpenAI / GPT 图像 API 后备
- 弹幕、评论
- Playwright 登录
- B站/抖音/小红书等大而全平台下载
- Web UI
- 说话人分离
- PDF / Word / 多格式笔记导出
- 为兼容旧 VideoNote-MCP 而保留的数据库、缓存和配置协议

## 商业化边界

目标是让本项目自己的代码来源清晰。

原则：

- 不复制 VideoNote-MCP 源代码。
- 不把 VideoNote-MCP 作为运行依赖。
- 第三方库和模型直接从其上游项目接入。
- 每个第三方依赖单独记录代码许可证、模型许可证、分发方式和商用注意事项。
- 正式发布前完成第三方依赖许可证审计。

参见根目录 `THIRD_PARTY.md`。
